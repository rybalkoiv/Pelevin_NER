# Именованные сущности в прозе Виктора Пелевина

## Общая характеристика

Набор содержит результаты извлечения и верификации упоминаний реальных персоналий и мифологических фигур в 22 крупных произведениях Виктора Пелевина 1993–2026 годов. Единица наблюдения — пара «произведение — именованная сущность». Для неё указаны частота упоминаний в произведении, виды деятельности, годы жизни и страна либо историческое государство, если эти сведения удалось получить.

Объём: 1456 записей, 745 уникальных сущностей, 22 произведения, 5673 суммарных упоминания.

Исследовательский вопрос: как в составе реальных персоналий, упоминаемых в прозе Виктора Пелевина, проявляются устойчивые структуры культурного воображаемого и изменение социального контекста постсоветского периода?

## Происхождение и подготовка данных

Исходным материалом служили электронные тексты произведений Виктора Пелевина. Полные тексты не входят в набор из-за авторских прав. Корпус включает 22 произведения, перечисленные в поле `work_title`; год первой публикации указан в `work_year`.

Подготовка состояла из следующих этапов:

1. Техническая очистка текста: удаление внешних кавычек строк, унификация тире и кавычек, сведение последовательностей пробельных символов к одному пробелу.
2. Независимое извлечение сущностей типа `PER` моделями Natasha/SlovNet и spaCy (`ru_core_news_lg`) с лемматизацией.
3. Объединение результатов двух моделей. Если сущность найдена обеими моделями, использована максимальная из двух частот, чтобы не удваивать одно и то же упоминание.
4. Поиск кандидатов в русскоязычной Википедии, переход к каноническому заголовку статьи и отбрасывание страниц неоднозначностей и записей без биографических маркеров.
5. Извлечение из вводной части статьи Википедии видов деятельности и, при наличии, годов жизни; страна или историческое государство добавлены из биографических сведений.
6. Ручная проверка результатов и маркировка 33 пар «произведение — сущность», где имя функционирует как персонаж художественного мира. Такие строки сохранены ради прозрачности, но имеют `exclude_as_character=true` и исключаются из тех расчётов статьи, где анализируются только внешние реальные референции.
7. Для публикационной версии целочисленные значения очищены от суффикса `.0`, названия произведений приведены к читаемому виду, варианты и опечатки в видах деятельности унифицированы, а годы до нашей эры записаны отрицательными целыми числами.

Сбор и обогащение выполнялись автоматически, а финальная выборка проверялась вручную. Метаданные Википедии могли измениться после момента сбора; набор фиксирует результат конкретного исследовательского процесса, а не исчерпывающий справочник персоналий.

## Состав набора

- `pelevin_named_entities.csv` — публикационная таблица, UTF-8, разделитель — запятая.
- `PelevinDataset.py` — не требующий внешних библиотек класс для загрузки, поиска и получения статистики.
- `Dataset_Usage.ipynb` — примеры работы с набором по образцу близкого NER-датасета Пушкинской энциклопедии.
- `Testing.ipynb` — воспроизводимые статистики и проверки набора.
- `Readme_en.md` — полная англоязычная документация.
- `validate_data.py` — тесты структуры и консистентности таблицы; внешние библиотеки не требуются.
- `prepare_dataset.py` — воспроизводимое преобразование исходной таблицы в публикационную.
- `requirements.txt` — зафиксированные зависимости примеров использования и тестового ноутбука.
- `source/pelevin_ner.py` — код извлечения и обогащения сущностей.
- `source/analize.ipynb` — очищенная от outputs и локальных путей копия аналитического notebook исследования.
- `source/result_original.csv` — неизменённая исходная таблица из репозитория.
- `source/README_original.md` — исходное краткое описание GitHub-репозитория.
- `source/requirements_pipeline.txt` — прямые зависимости исходного конвейера и анализа с версиями из сохранённого рабочего окружения авторов.
- `CHANGELOG.md` — история версий публикуемого набора.

## Поля таблицы

- `work_title` — унифицированное название произведения.
- `work_year` — год первой публикации произведения.
- `entity` — каноническое имя сущности, как правило заголовок статьи русскоязычной Википедии.
- `mention_count` — число упоминаний сущности в данном произведении по результату объединённого NER-конвейера.
- `activities` — ноль, один или несколько видов деятельности; множественные значения разделены вертикальной чертой `|`, пустое значение означает, что вид деятельности не был извлечён.
- `birth_year` — год рождения; пусто, если не определён. Годы до н. э. представлены отрицательными числами.
- `death_year` — год смерти; пусто, если не определён или персоналия жива. Годы до н. э. представлены отрицательными числами.
- `country_or_polity` — страна, место или историческое государство, связанное с персоналией; пусто, если не определено. Значения отражают историческую терминологию источника и не сведены к современным государствам.
- `exclude_as_character` — `true`, если конкретное упоминание было вручную отмечено как персонаж художественного мира и исключалось из соответствующих анализов статьи; иначе `false`.

## Проверка консистентности

Из каталога с файлами выполните:

```bash
python3 validate_data.py
```

Тесты проверяют схему, число записей/произведений/сущностей/упоминаний, уникальность ключа `work_title + entity`, допустимость чисел и унификацию категорий.

## Пример использования

```python
from PelevinDataset import PelevinDataset

dataset = PelevinDataset("pelevin_named_entities.csv")
dataset.summary()
dataset.get_sample_by_id(10)
dataset.get_entities_by_work("Generation «П»", include_characters=False)
dataset.get_occurrences_by_entity("Оруэлл, Джордж")
dataset.get_entities_by_activity("писатель")
```

## Ограничения

- Корпус охватывает 22 крупных произведения, но не является полным собранием сочинений Пелевина; объёмы произведений различаются.
- Автоматический NER и связывание с Википедией неизбежно дают пропуски и ошибочные совпадения, несмотря на ручную проверку.
- `mention_count` получен как максимум частот двух моделей, а не по золотой ручной разметке.
- Пустой `death_year` неоднозначен: персоналия могла быть живой на момент сбора либо год не был извлечён.
- `country_or_polity` неоднородно сочетает современные страны, исторические государства и места происхождения; для регионального анализа в ноутбуке применяется отдельная ручная группировка.
- Для двух строк вид деятельности не был извлечён и поле `activities` оставлено пустым.
- Версии прямых зависимостей восстановлены из сохранённого рабочего окружения и записаны в `source/requirements_pipeline.txt`. Аналитический notebook был создан под Python 3.12.3; переносимость на другие версии Python отдельно не проверялась.
- Даты 2026 года относятся к состоянию корпуса и статьи на момент подготовки набора.
- Публичный код не содержит отдельного сохранённого этапа, который запускает NER для всех 22 текстов, добавляет страну и объединяет результаты в `result_original.csv`; полная цепочка от исходных текстов воспроизводится не целиком.
- Анализы, нормированные на длину произведения, требуют закрытого локального каталога `texts/` и не воспроизводятся из публичного пакета без законно полученных исходных текстов.
- До подачи требуется содержательная сверка биографических годов и видов деятельности: аудит выявил противоречивые значения у повторяющихся сущностей и ошибки представления дат до н. э.

Библиографический статус самой поздней позиции корпуса проверен по сайту издательства: В. О. Пелевин, «Возвращение Синей Бороды», Эксмо, 2026, ISBN 978-5-04-241368-1; начало продаж — 23 апреля 2026 года.
