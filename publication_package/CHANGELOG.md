# Changelog

## 1.0 — черновик для рецензирования

- Подготовлена публикационная таблица из `result.csv` репозитория.
- Добавлены годы произведений и флаг ручного исключения упоминаний-персонажей.
- Целые числа очищены от суффикса `.0`.
- Виды деятельности сериализованы через `|`; исправлены четыре неунифицированных варианта.
- Годы до нашей эры представлены отрицательными целыми числами.
- Названия трёх произведений очищены от технических подчёркиваний и повторных пробелов.
- Добавлены README и автоматические тесты консистентности.
- Структура приближена к NER-датасету «Именованные сущности в Пушкинской энциклопедии»: добавлены английский README, программный класс доступа, usage notebook и testing notebook.
- Прямые зависимости отобраны из полного рабочего `pip freeze` (518 пакетов) и зафиксированы; неиспользуемый импорт NLTK удалён из публикационной копии конвейера.
- Метаданные уточнены: ORCID у обоих авторов отсутствует, идентификаторы авторов в Dataverse следует оставить пустыми.
- `analize.ipynb` очищен от 40 outputs, execution counts и локального пути коллеги; исправлены путь к CSV, тип `is_character`, индексы после `explode()` и порядок разбора `activities`.
- Расширенный аудит выявил необходимость содержательной сверки противоречивых биографических метаданных до подачи.
