# Материалы для продолжения работы над Pelevin NER

Эта ветка собирает локальные наработки по подготовке набора Pelevin NER к публикации в DataVerse ИРЛИ. Это рабочая передача проекта соавтору, а не готовый релиз датасета.

## С чего начать

1. Прочитать `handoff/SESSION_HANDOFF.md`.
2. Прочитать `handoff/AUDIT_REPORT.md`.
3. Разобрать сигналы из `handoff/DATA_REVIEW_REQUIRED.csv`.
4. Согласовать правила нормализации биографических дат и видов деятельности.
5. После исправлений пересобрать CSV, пересчитать анализ и запустить `python3 publication_package/validate_data.py`.

## Состав

- `publication_package/` — подготовленный пакет данных, документации, кода и notebooks.
- `handoff/` — состояние работы, аудит качества, список проблем и инструкции по будущей подаче.
- `reference_example_pushkin/` — локально сохранённые вспомогательные файлы близкого опубликованного NER-датасета, использованного как ориентир структуры.
- `analize.ipynb` — очищенный локальный notebook исходного проекта (незакоммиченное ранее изменение).

## Статус

Структурные тесты проходят, но набор пока нельзя считать готовым к публикации: аудит выявил 124 сигнала качества в биографических метаданных. Они могут влиять на эпохи, графики, статистические тесты и выводы статьи.

Существующие локальные ZIP `pelevin_dataverse_draft_v1.0`–`v1.3` в ветку не включены: они устарели и созданы до финального аудита.

## Референсный датасет

«Именованные сущности в Пушкинской энциклопедии», Кассаб Кенан, Тесля Николай, Вожик Екатерина, V1, DataVerse ИРЛИ:

- DOI: https://doi.org/10.31860/openlit-2024.7-A001
- страница набора: https://dataverse.pushdom.ru/dataset.xhtml?persistentId=doi:10.31860/openlit-2024.7-A001
- лицензия исходного набора: CC0.

Файлы в `reference_example_pushkin/` нужны только как ориентир для структуры README, usage/testing notebooks и программного интерфейса. Они не являются частью Pelevin NER.

## Что намеренно не включено

- `article.docx` — рукопись содержит контактные данные авторов;
- полные тексты произведений — из-за авторских прав;
- HTML/TXT/JSON-снимки сайтов и второй общий пример — вместо них оставлены прямые ссылки;
- старые ZIP, `__pycache__`, `.DS_Store` и другие локальные артефакты.
